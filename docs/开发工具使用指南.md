# AutoFlowCFD 开发工具使用指南

## 概述

本指南提供可靠的代码测试和验证方法，避免终端输出丢失问题。

---

## 一、推荐工作流程

### 1.1 标准验证流程（按优先级）

```
1. get_problems()     ← 最可靠，优先使用
   ↓ (无错误)
2. 单元测试            ← 使用tests.test_utils模块
   ↓ (通过)
3. 集成测试            ← 端到端验证
   ↓ (通过)
4. 手动运行CLI         ← 最终确认
```

### 1.2 每次代码修改后的检查清单

```python
# ✅ 步骤1: 语法检查（立即执行）
from autoflowcfd import get_problems
get_problems(file_paths=["src/autoflowcfd/new_module.py"])

# ✅ 步骤2: 单元测试（如果步骤1通过）
from tests.test_utils import run_pytest
output = run_pytest("tests/unit/test_new_module.py")
print(output)

# ✅ 步骤3: 导入测试（快速验证）
from tests.test_utils import verify_module_import
result = verify_module_import("autoflowcfd.new_module")
assert result['success'], result['error']

# ✅ 步骤4: 功能测试（可选）
from tests.test_utils import run_command
result = run_command("python scripts/verify_feature.py")
if result['success']:
    print(result['stdout'])
```

## 二、测试工具模块使用

### 2.1 导入工具模块

```python
from tests.test_utils import (
    run_pytest,           # 运行pytest
    run_command,          # 运行任意命令
    verify_module_import, # 验证模块导入
    check_code_syntax,    # 检查语法
    run_all_unit_tests,   # 运行所有单元测试
)
```

### 2.2 运行单元测试

```python
# 单个测试文件
output = run_pytest("tests/unit/test_boundary.py")
print(output)

# 单个测试类
output = run_pytest("tests/unit/test_boundary.py::TestInletBC")
print(output)

# 单个测试方法
output = run_pytest("tests/unit/test_boundary.py::TestInletBC::test_creation_with_defaults")
print(output)

# 所有单元测试
output = run_all_unit_tests()
print(output)
```

### 2.3 运行任意命令

```python
# 运行验证脚本
result = run_command("python scripts/verify_iteration4.py", timeout=60)

if result['success']:
    print("✅ 验证通过")
    print(result['stdout'])
else:
    print("❌ 验证失败")
    print(result['stderr'])
```

### 2.4 验证模块导入

```python
# 验证核心模块
modules_to_check = [
    "autoflowcfd.boundary",
    "autoflowcfd.cli",
    "autoflowcfd.api",
    "autoflowcfd.config",
]

for module in modules_to_check:
    result = verify_module_import(module)
    status = "✅" if result['success'] else "❌"
    print(f"{status} {module}: {'OK' if result['success'] else result['error']}")
```

### 2.5 检查代码语法

```python
# 检查单个文件
result = check_code_syntax("src/autoflowcfd/api.py")
if result['valid']:
    print("✅ 无语法错误")
else:
    print("❌ 语法错误:")
    for error in result['errors']:
        print(f"  - {error}")
```

## 三、Click CLI测试（无需终端）

### 3.1 使用CliRunner（推荐）

```python
from click.testing import CliRunner
from autoflowcfd.cli.main import cli

def test_cli_commands():
    runner = CliRunner()
    
    # 测试主帮助
    result = runner.invoke(cli, ["--help"])
    assert result.exit_code == 0
    print(result.output)
    
    # 测试子命令
    result = runner.invoke(cli, ["grid", "--help"])
    assert result.exit_code == 0
    
    # 测试带参数的命令
    result = runner.invoke(cli, ["utils", "version", "--json"])
    assert result.exit_code == 0
    
    import json
    version_info = json.loads(result.output)
    print(f"Version: {version_info['autoflowcfd']}")
```

**优势**：
- ✅ 完全不依赖终端
- ✅ 输出100%可靠捕获
- ✅ 可以模拟用户输入
- ✅ 支持退出码检查

### 3.2 编写CLI测试用例

```python
import pytest
from click.testing import CliRunner
from autoflowcfd.cli.main import cli

class TestCLIGridCommands:
    
    def setup_method(self):
        self.runner = CliRunner()
    
    def test_grid_parse_help(self):
        """Test grid parse help output"""
        result = self.runner.invoke(cli, ["grid", "parse", "--help"])
        
        assert result.exit_code == 0
        assert "--output" in result.output
        assert "--streaming" in result.output
    
    def test_grid_validate_with_json(self):
        """Test grid validate with JSON output"""
        # 假设有测试网格文件
        result = self.runner.invoke(
            cli,
            ["grid", "validate", "tests/data/test.nas", "--json"]
        )
        
        if result.exit_code == 0:
            import json
            report = json.loads(result.output)
            assert "error_count" in report
```

## 四、常见问题与解决方案

### 4.1 问题：终端输出为空

**原因**：
- VSCode终端配置问题
- 命令执行太快，输出缓冲区未准备好
- PowerShell编码问题

**解决方案**：
```python
# ❌ 不要这样做
run_in_terminal(command="python script.py")
# 然后期望能获取输出

# ✅ 正确做法1: 使用subprocess（完全绕过终端）
from tests.test_utils import run_command
result = run_command("python script.py")
print(result['stdout'])

# ✅ 正确做法2: 使用Click的CliRunner（针对CLI）
from click.testing import CliRunner
runner = CliRunner()
result = runner.invoke(cli, ["command"])
print(result.output)

# ✅ 正确做法3: 使用get_problems（针对语法检查）
get_problems(file_paths=[...])
```

### 4.2 问题：长时间运行的命令超时

**解决方案**：
```python
# 设置合理的超时时间
result = run_command(
    "python -m pytest tests/ -v",
    timeout=300  # 5分钟
)

# 对于极长的测试，分批运行
test_files = [
    "tests/unit/test_boundary.py",
    "tests/unit/test_cli.py",
    "tests/unit/test_api.py",
]

for test_file in test_files:
    output = run_pytest(test_file)
    print(f"\n{'='*60}")
    print(f"Results for {test_file}")
    print('='*60)
    print(output)
```

### 4.3 问题：交互式命令无法自动化

**解决方案**：
```python
# ❌ 避免交互式命令
# input(), click.prompt(), 等

# ✅ 改用命令行参数
command = "python script.py --input data.nas --output result.json --verbose"
result = run_command(command)

# ✅ 或使用环境变量
import os
os.environ['AUTOFLOWCFD_CONFIG'] = 'config.yaml'
result = run_command("python script.py")
```

### 4.4 问题：Windows PowerShell编码问题

**解决方案**：
```python
# 方法1: 在命令中设置编码
command = "chcp 65001 >nul && python script.py"
result = run_command(command)

# 方法2: 使用subprocess时指定编码
result = subprocess.run(
    command,
    shell=True,
    capture_output=True,
    text=True,
    encoding='utf-8',
    errors='replace'  # 自动处理编码错误
)
```

## 五、迭代开发中的最佳实践

### 5.1 开发新功能时的验证流程

```python
# 1. 创建新模块后
new_file = "src/autoflowcfd/new_feature.py"

# 2. 立即检查语法
result = check_code_syntax(new_file)
assert result['valid'], f"Syntax errors: {result['errors']}"

# 3. 验证导入
result = verify_module_import("autoflowcfd.new_feature")
assert result['success'], result['error']

# 4. 运行相关测试
output = run_pytest("tests/unit/test_new_feature.py")
assert "passed" in output.lower() or "PASSED" in output

# 5. 运行完整测试套件（最后）
output = run_all_unit_tests()
print(output)
```

### 5.2 CI/CD中的自动化测试

```yaml
# .github/workflows/test.yml
name: Tests
on: [push, pull_request]

jobs:
  test:
    runs-on: windows-latest
    
    steps:
      - uses: actions/checkout@v2
      
      - name: Install dependencies
        run: pip install -e .[dev]
      
      - name: Run syntax check
        run: |
          python -c "
          from tests.test_utils import check_code_syntax
          import glob
          for file in glob.glob('src/**/*.py', recursive=True):
              result = check_code_syntax(file)
              assert result['valid'], f'{file}: {result[\"errors\"]}'
          "
      
      - name: Run unit tests
        run: python -m pytest tests/unit/ -v --cov
      
      - name: Run integration tests
        run: python -m pytest tests/integration/ -v
```

### 5.3 本地快速验证脚本

创建 `scripts/quick_verify.py`：

```python
#!/usr/bin/env python
"""Quick verification script for local development."""

import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).parent.parent / "tests"))

from test_utils import (
    verify_module_import,
    run_pytest,
    check_code_syntax,
)

def main():
    print("=" * 60)
    print("AutoFlowCFD Quick Verification")
    print("=" * 60)
    
    # 1. Check core modules
    print("\n1. Checking core modules...")
    modules = [
        "autoflowcfd",
        "autoflowcfd.boundary",
        "autoflowcfd.cli",
        "autoflowcfd.api",
        "autoflowcfd.config",
    ]
    
    all_ok = True
    for module in modules:
        result = verify_module_import(module)
        status = "✅" if result['success'] else "❌"
        print(f"  {status} {module}")
        if not result['success']:
            all_ok = False
            print(f"     Error: {result['error']}")
    
    if not all_ok:
        print("\n❌ Module import checks failed")
        return 1
    
    # 2. Run critical tests
    print("\n2. Running critical tests...")
    critical_tests = [
        "tests/unit/test_boundary.py",
        "tests/unit/test_api.py",
    ]
    
    for test_file in critical_tests:
        print(f"\n  Testing: {test_file}")
        output = run_pytest(test_file, verbose=False)
        
        if "passed" in output.lower() or "PASSED" in output:
            print(f"  ✅ PASSED")
        else:
            print(f"  ❌ FAILED")
            print(output)
            all_ok = False
    
    # Summary
    print("\n" + "=" * 60)
    if all_ok:
        print("✅ All quick checks passed!")
        return 0
    else:
        print("❌ Some checks failed. Review output above.")
        return 1

if __name__ == "__main__":
    sys.exit(main())
```

使用方法：
```bash
python scripts/quick_verify.py
```

## 六、总结与建议

### 6.1 优先级排序

| 方法 | 可靠性 | 速度 | 适用场景 |
|------|--------|------|----------|
| `get_problems()` | ⭐⭐⭐⭐⭐ | 快 | 语法检查 |
| `CliRunner` | ⭐⭐⭐⭐⭐ | 快 | CLI测试 |
| `test_utils.run_pytest()` | ⭐⭐⭐⭐⭐ | 中 | 单元测试 |
| `test_utils.run_command()` | ⭐⭐⭐⭐ | 中 | 通用命令 |
| `run_in_terminal()` + `get_terminal_output()` | ⭐⭐⭐ | 慢 | 最后手段 |

### 6.2 黄金法则

1. **永远优先使用不依赖终端的方法**
   - `get_problems()` > `CliRunner` > `subprocess` > `run_in_terminal()`

2. **编写可测试的代码**
   - 避免交互式输入
   - 使用命令行参数
   - 模块化设计便于单元测试

3. **建立自动化验证流程**
   - 每次提交前运行`quick_verify.py`
   - CI/CD自动运行完整测试套件
   - 保持测试覆盖率≥80%

4. **遇到问题时的应对**
   - 第一步：尝试替代方法（如CliRunner代替终端）
   - 第二步：创建独立测试脚本
   - 第三步：请求用户手动提供输出
